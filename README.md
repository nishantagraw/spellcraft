# ✨ SpellCraft Studio

> An aesthetic, interactive English spelling, grammar, and pronunciation mastery platform designed for Hindi & Hinglish speakers to build confident written English.

🌐 **Live Web App**: [https://nishantagraw.github.io/spellcraft/](https://nishantagraw.github.io/spellcraft/)

---

## 🚀 Key Features

- **1,250+ Vocabulary Words**: Hand-curated essential daily English words categorized across Beginner, Intermediate, Advanced, and Mastery levels.
- **Hinglish & Hindi Support**: Every word includes a Hinglish phonetic reading guide (e.g., *kruh-DAYN-shulz*), clear Hindi meanings, and memorable spelling mnemonics.
- **Voice Dictation & Spell Check**: Hear real human-like speech pronunciation and type what you hear. Words you get right in one go are never repetitively asked in the same session.
- **Paragraph Dictation & Real-Time Diff**: Listen to full real-life English passages, type them out, and get an instant word-by-word comparison identifying spelling mistakes and punctuation issues.
- **Grammar Studio**: Master tricky everyday grammar rules—Articles (*a / an / the*), Prepositions (*in / on / at*), Subject-Verb agreement, and punctuation rules.
- **Chunk Builder & Spot The Trap**: Break words into intuitive sound blocks and catch silent letters or spelling traps before they trick you.
- **Tricky Word Vault**: Save words that challenge you for focused revision.
- **Aesthetic Themes**: Default Instagram Charcoal Dark mode, plus Matcha, Sunset, Bubblegum, Cyberpunk, and Cozy Warmth themes.
- **100% Free & Client-Side**: No backend required; works directly in any browser and saves your progress locally.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3** (CSS custom properties, glassmorphism, responsive grid)
- **Vanilla JavaScript (ES6+)**
- **Web Speech API** (`SpeechSynthesis` for native speech playback)
- **Web Audio API** (Custom UI sound effects & tones)
- **LocalStorage** (Persistent XP, level unlocks, streaks, and vault words)

---

## 💻 Running Locally

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/nishantagraw/spellcraft.git
cd spellcraft
# Open index.html directly in your browser!
```
